CC

Claude Code

Conexión directa con tu API personal

¿Aparece “claude no se reconoce”?Significa que Claude Code no está instalado o que falta su carpeta en el PATH. Ejecuta completo el paso 1.
Ahora Claude Code usa directamente tu claveLa URL base es {{ provider_base_url }} y el token es la API personal sk-... mostrada arriba. El token nxa_... no se utiliza en Claude Code.
  1. Instala y verifica Claude CodeCopia y ejecuta todo este bloque en PowerShell. Instala Claude Code, corrige el PATH y muestra la versión:
irm https://claude.ai/install.ps1 | iex
$claudeDir = "$env:USERPROFILE\.local\bin"
$env:Path = "$env:Path;$claudeDir"
$userPath = [Environment]::GetEnvironmentVariable("Path", "User")
if (($userPath -split ";") -notcontains $claudeDir) {
  [Environment]::SetEnvironmentVariable("Path", "$userPath;$claudeDir", "User")
}
claude --version
Si el instalador falla o sigue sin reconocer claude

Comprueba si existe el ejecutable:

Test-Path "$env:USERPROFILE\.local\bin\claude.exe"
& "$env:USERPROFILE\.local\bin\claude.exe" --version

Si el primer comando devuelve False, instala la alternativa oficial con:

winget install Anthropic.ClaudeCode
  1. Conecta tu API personalPulsa “Copiar con mi API”; Nexia insertará tu clave sk-... en el bloque antes de copiarlo:
$env:ANTHROPIC_BASE_URL="{{ provider_base_url }}"
$env:ANTHROPIC_AUTH_TOKEN="TU_API_PERSONAL_SK"
$headers = @{ Authorization = "Bearer $env:ANTHROPIC_AUTH_TOKEN" }
Invoke-RestMethod "{{ provider_base_url }}/models" -Headers $headers
claude --model claude-sonnet-4-6
Guardar la conexión de forma permanente

Crea o edita %USERPROFILE%\.claude\settings.json:

{
  "env": {
    "ANTHROPIC_AUTH_TOKEN": "TU_API_PERSONAL_SK",
    "ANTHROPIC_BASE_URL": "{{ provider_base_url }}",
    "ANTHROPIC_DEFAULT_HAIKU_MODEL": "claude-sonnet-4-6",
    "ANTHROPIC_DEFAULT_OPUS_MODEL": "claude-sonnet-4-6",
    "ANTHROPIC_DEFAULT_SONNET_MODEL": "claude-sonnet-4-6",
    "CLAUDE_CODE_ENABLE_TELEMETRY": "0"
  }
}
  1. Verifica la conexiónEl comando debe listar los modelos de MWAPI antes de abrir Claude Code. Ya dentro, escribe /status y confirma que la URL base sea {{ provider_base_url }}.
El consumo de la terminal se descontará directamente del mismo saldo real mostrado en Nexia. Al entregar la clave directa, los límites de modelos en terminal dependen del proveedor.
