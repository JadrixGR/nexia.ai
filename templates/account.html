CC

Claude Code

Formato Anthropic compatible

En PowerShell, configura estas variables antes de abrir Claude Code:

$env:ANTHROPIC_BASE_URL="{{ public_base_url }}/api/anthropic"
$env:ANTHROPIC_AUTH_TOKEN="TU_TOKEN_NEXIA"
claude --model claude-sonnet-4-6
Las herramientas dependen de que el proveedor compatible las procese correctamente.
CX

ChatGPT Codex

Protocolo Responses compatible

Añade esto a ~/.codex/config.toml:

model = "claude-sonnet-4-6"
model_provider = "nexia"

[model_providers.nexia]
name = "Nexia"
base_url = "{{ public_base_url }}/v1"
env_key = "NEXIA_API_KEY"
wire_api = "responses"

Después define $env:NEXIA_API_KEY="TU_TOKEN_NEXIA".
