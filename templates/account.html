CC

Claude Code

Formato Anthropic compatible

¿Aparece “claude no se reconoce”?Significa que Claude Code no está instalado o que falta su carpeta en el PATH. Ejecuta completo el paso 2.
  1. Genera tu token NexiaUsa el botón superior. El token empieza con nxa_.
  2. Instala y verifica Claude CodeCopia y ejecuta todo este bloque en PowerShell. Instala Claude Code, corrige el PATH y muestra la versión:
irm https://claude.ai/install.ps1 | iex
$claudeDir = "$env:USERPROFILE\.local\bin"
$env:Path = "$env:Path;$claudeDir"
$userPath = [Environment]::GetEnvironmentVariable("Path", "User")
if (($userPath -split ";") -notcontains $claudeDir) {
  [Environment]::SetEnvironmentVariable("Path", "$userPath;$claudeDir", "User")
}
claude --version
Si el instalador falla o sigue sin reconocer claude

Comprueba si existe el ejecutable:

Test-Path "$env:USERPROFILE\.local\bin\claude.exe"
& "$env:USERPROFILE\.local\bin\claude.exe" --version

Si el primer comando devuelve False, instala la alternativa oficial con:

winget install Anthropic.ClaudeCode
  1. Conecta Claude Code con NexiaEn la carpeta de tu proyecto, abre PowerShell y ejecuta:
$env:ANTHROPIC_BASE_URL="{{ public_base_url }}/api/anthropic"
$env:ANTHROPIC_AUTH_TOKEN="TU_TOKEN_NEXIA"
claude --model claude-sonnet-4-6
Guardar la conexión de forma permanente

Crea o edita %USERPROFILE%\.claude\settings.json:

{
  "env": {
    "ANTHROPIC_BASE_URL": "{{ public_base_url }}/api/anthropic",
    "ANTHROPIC_AUTH_TOKEN": "TU_TOKEN_NEXIA"
  }
}
  1. Verifica la conexiónDentro de Claude Code escribe /status. Debe mostrar la URL de Nexia. Después ya puedes pedirle que lea, cree o modifique archivos del proyecto.
El consumo hecho desde la terminal utiliza directamente el saldo real de la API asignada a tu cuenta. Las llamadas de herramientas requieren compatibilidad del modelo proveedor.
CX

ChatGPT Codex

Protocolo Responses compatible

  1. Instala Codex CLINecesitas Node.js y npm:
npm install -g @openai/codex
  1. Configura el proveedor NexiaCrea o edita %USERPROFILE%\.codex\config.toml:
model = "claude-sonnet-4-6"
model_provider = "nexia"

[model_providers.nexia]
name = "Nexia"
base_url = "{{ public_base_url }}/v1"
env_key = "NEXIA_API_KEY"
wire_api = "responses"
requires_openai_auth = false
  1. Abre tu proyecto con el tokenEn PowerShell ejecuta:
$env:NEXIA_API_KEY="TU_TOKEN_NEXIA"
cd "C:\ruta\de\tu\proyecto"
codex
  1. Comprueba y trabajaEjecuta /status y confirma el proveedor nexia. Codex podrá trabajar con los archivos y la terminal de esa carpeta.
No compartas el token ni lo guardes en GitHub, capturas o archivos del proyecto.
